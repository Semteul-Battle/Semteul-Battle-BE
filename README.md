## 🏆 Semteul-Battle

### 📌 프로젝트 소개
**Semteul-Battle**은 알고리즘 문제 풀이와 대회 개최를 지원하는 웹 플랫폼입니다.  
사용자는 문제를 풀고, 랭킹을 확인하며, 대회를 직접 개최할 수도 있습니다.  
개발 재개(2025.09.11~ )
